- Problem (confirmed): Even pi builds some features into its core, so there was no headless harness you could control completely, where everything is a plugin and the core is only as big as you need. popeye started from curiosity about what that harness would look like.
- Occasion (confirmed): You want a minimal harness with only the plugins you add, a headless harness for hcn to drive, a harness you can point at any OpenAI-compatible endpoint, or a durable core to build your own agent host on.
- Incumbent (confirmed): pi, which has extensions but builds some features into its core.
- Value (confirmed): The harness carries only the plugins you load, so nothing you didn't ask for is in the model's tools or context. First-party features such as goals, compaction and delegation use the same plugin API as yours, so you can drop or replace any of them.
- Non-goals (confirmed): It's headless, with no TUI. It ships no file or shell tools; you add them as plugins. If you want a harness that does everything as soon as it's installed, use pi. It's a personal experiment, before 1.0, shaped around its author's needs.
