# Security policy

## Supported versions

The latest `0.x` release only. Earlier prereleases get no patches.

## Reporting a vulnerability

Open a GitHub issue with the `security` label, or contact the
maintainer directly. Include:

- What the flaw lets an attacker do.
- The smallest reproduction you have.
- Which version you tested.

Expect an acknowledgment within 7 days. Do not open a public
exploit before a fix ships.
